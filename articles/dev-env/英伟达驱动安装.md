# 英伟达显卡驱动Nvidia driver的安装

n次安装。最后一次总结！

# 下载驱动

官方驱动下载地址：https://www.nvidia.com/Download/index.aspx?lang=cn

操作系统：根据架构进行选择

架构为X86_64时选择Linux 64-bit

架构为arm64时选择Lniux Aarch64

CUDA Toolkit：一般选择Any，若版本太高，尝试指定cuda版本



## 安装英伟达驱动流程

如果是驱动版本不对，要卸载了重装。那么：

1. 卸载原有驱动

2. 退出图形界面

3. 运行安装脚本

如果是刚装了ubuntu 系统要装驱动。那么：

1. 退出图形界面

2. 禁用开源的nouveau驱动

3. 运行安装脚本

### 卸载原有驱动

卸载命令位置/usr/bin/nvidia-uninstall

```bash
nvidia-uninstall
sudo /usr/bin/nvidia-uninstall
```

或者

sudo apt-get --purge remove nvidia*
sudo apt autoremove



### 退出图形界面

按住ctrl+alt+F1（1-6均可），进入x-server
禁用图形界面。
```bash
sudo service lightdm stop
```
或者
```
# 查看
sudo systemctl status lightdm  
systemctl stop lightdm
sudo systemctl status lightdm
```

如果提示unit lightdm.service not loaded
则需要安装LightDm：
sudo apt install lightdm
安装完毕后跳出一个界面，选择lightdm，
再sudo service lightdm stop。

### 禁用开源的nouveau驱动
编辑配置文件
```bash
sudo vim /etc/modprobe.d/blacklist.conf
```
在文本末添加：
blacklist nouveau
options nouveau modeset=0
执行：
```bash
sudo update-initramfs -u
```
电脑重启一下
输入以下命令若无显示，即为禁用成功
lsmod |grep nouveau 

### 安装驱动
```bash
#添加执行权限
chmod a+x NVIDIA-Linux-aarch64-460.106.00.run
# 运行安装
./NVIDIA-Linux-aarch64-460.106.00.run
```

1）根据出现的提示安装驱动，选择yes、accept等选项。

以下三个选项出现时需要选择no，其他均为yes或accept

（1）Would you like to register the kernel module sources with DKMS?This will allow DKMS to auomatically build a new module,if you install a different kernel later？选择No

（2）Install Nvidia’s 32-bit compatibility libraries? 选择 No

（3）Would you like to run the nvidia-xconfig utility to automatically update your X configuration file so that the NVIDIA X driver will be user whten you rest…”选择 No



### 验证安装完成

查看驱动版本，显卡信息。

```bash
nvidia-smi
```

可以看到显卡驱动信息，driver cuda的版本。即显卡驱动安装成功。

可以进一步安装runtime cuda或者使用docker中的cuda。



回到图形界面或直接将电脑重启，建议安装完成后重启下电脑。

```bash
service lightdm start            #重启图形界面
reboot now                       #重启
```
