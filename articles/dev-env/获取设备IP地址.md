将设备使用网线和本地电脑直连

本地电脑终端输入

```
sudo tcpdump
```

这是会打印连接设备的ip地址。

```
ping 192.168.1.11
```



将pc只和板子用网线进行直连，如果输入`sudo tcpdump`得到了来自某个ip的arp请求，那么这个ip就是板子的ip，要和板子ping通的话记得添加本地静态ip。

比如找到的板子的ip是192.168.12.1, 用这个命令

```bash
sudo ifconfig enp2s0:0 192.168.12.2 netmask 255.255.255.0 up
```

将本地静态ip改到和板子同一网段
