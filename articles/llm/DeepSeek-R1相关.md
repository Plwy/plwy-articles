### 训练成本

**训练资源消耗**
	DeepSeek-V3 使用 H800 GPU 集群进行训练，总耗时约 2788K GPU 小时，整个训练过程的成本不超过 600 万美元。为了进一步降低成本，DeepSeek 利用了稀疏计算设计、改进的注意力机制、高效的资源分配、课程学习、动态批处理等技术。这些措施共同作用，大大降低了整体的训练资源消耗。

​	DeepSeek-R1 的训练成本显著低于同类产品。据资料，其预训练费用仅为 557.6 万美元，而 OpenAI 同规格模型的训练成本高达 7800 万美元。这意味着 DeepSeek-R1 以不到十分之一的成本实现了足以与顶级模型竞争的性能。

### 模型推理部署成本及方案

在推理成本方面，DeepSeek 提供极具竞争力的 API 定价，每百万输入 tokens 只要 1 - 4 元，每百万输出 tokens 只要 16 元，这个收费大约只有 OpenAI 对应模型运行成本的三十分之一。DeepSeek 支持云端调用和本地部署两种方式，云端调用适合中小企业和创业公司，而本地部署则适合对数据安全有较高要求的企业。

### DeepSeek-V3模型网络架构

- **DeepSeekMoE**：一种高效的混合专家模型架构，允许模型仅激活部分计算单元来执行特定任务，从而提高了能效和资源利用率。
- **MLA 多头潜在注意力**：这项技术进一步压缩了推理所需的内存，降低了推理成本。

### 训练推理核心技术
- **训练框架HAI-LLM**：这是DeepSeek开发的一个高效训练框架，支持大规模语言模型的训练。
- **核心算法DualPipe**：一个创新的流水线并行算法，用于提高训练效率。
- **FP8训练的混合精度框架**：利用混合精度计算以减少训练期间的内存占用和计算需求。

DeepSeek R1 主要采用纯强化学习（RL）进行训练，这种方法减少了对大量人工标注数据的依赖，同时提高了模型在自我博弈中的推理能力。此外，DeepSeek 还采用了创新的**GRPO（Group Relative Policy Optimization）算法**框架来优化强化学习的训练过程。
