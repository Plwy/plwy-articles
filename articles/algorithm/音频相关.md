

## 音频文件格式

音频文件有多种格式，不同的后缀代表了不同的编码方式、压缩算法和用途。以下是常见的音频文件后缀及其区别：

### **常见音频文件格式**

音频文件有多种格式，不同的后缀代表了不同的编码方式、压缩算法和用途。以下是常见的音频文件后缀及其区别：

#### **无损音频格式**

- **WAV (.wav)**  
  - **特点**：未压缩的音频格式，音质极高，但文件体积大。
  - **用途**：常用于专业音频制作、录音和存储高质量音频。
- **PCM (.pcm)**  
  - **特点**：PCM（Pulse Code Modulation）是未压缩的原始音频数据格式，类似于 WAV，但没有文件头信息。它直接存储音频采样数据，因此音质非常高，但文件体积也很大。
  - **用途**：常用于音频处理、编码和解码过程中作为中间格式，或者在专业音频设备中使用。
- **FLAC (.flac)**  
  - **特点**：无损压缩音频格式，保留原始音频质量，文件体积比 WAV 小。
  - **用途**：适合需要高质量音频但又希望节省存储空间的场景。
- **ALAC (.alac 或 .m4a)**  
  - **特点**：苹果开发的无损音频格式，与 FLAC 类似。
  - **用途**：主要用于 Apple 生态系统中的高质量音频。

---

#### **有损音频格式**

- **MP3 (.mp3)**  
  - **特点**：最流行的音频格式，采用有损压缩，文件体积小，音质相对较高。
  - **用途**：广泛用于音乐播放、网络传输等。

- **AAC (.aac 或 .m4a)**  
  - **特点**：高级音频编码格式，比 MP3 更高效，音质更好，文件更小。
  - **用途**：iTunes、YouTube 和流媒体服务常用格式。

- **OGG (.ogg)**  
  - **特点**：开源音频格式，支持有损压缩，音质较好。
  - **用途**：常用于互联网音频流和游戏音频。

- **WMA (.wma)**  
  - **特点**：微软开发的音频格式，类似于 MP3，但兼容性较差。
  - **用途**：Windows 系统中使用较多。

---

#### **其他特殊格式**

- **OPUS (.opus)**  
  - **特点**：OPUS 是一种专为互联网实时传输设计的音频编码格式，支持低延迟和高质量的音频压缩。它能够在非常低的比特率下提供出色的音质，同时兼容多种采样率（从 8 kHz 到 48 kHz）。
  - **用途**：广泛用于 VoIP（网络电话）、视频会议、流媒体播放以及需要低延迟音频传输的场景。
- **MIDI (.mid 或 .midi)**  
  - **特点**：不是音频文件，而是乐器数字接口文件，存储的是音符信息而非声音波形。
  - **用途**：用于音乐创作和合成器。
- **AIFF (.aiff)**  
  - **特点**：苹果开发的无压缩音频格式，类似于 WAV。
  - **用途**：专业音频编辑和存储。
- **AMR (.amr)**  
  - **特点**：专为语音设计的压缩格式，文件体积极小。
  - **用途**：手机语音通话记录。
- **DTS (.dts)**  
  - **特点**：高保真环绕声格式，常用于电影和家庭影院。
  - **用途**：蓝光和 DVD 音轨。
- **APE (.ape)**  
  - **特点**：无损压缩格式，类似于 FLAC，但解压速度较慢。
  - **用途**：高质量音频存储。

#### 不同格式区别

> 语音识别系统通常会优先选择以下加粗的格式进行处理。

| 格式     | 是否无损 | 文件大小 | 音质       | 主要用途                     |
| -------- | -------- | -------- | ---------- | ---------------------------- |
| **WAV**  | **是**   | **大**   | **极高**   | **专业音频制作**             |
| **FLAC** | **是**   | **中**   | **极高**   | **高质量音频存储**           |
| ALAC     | 是       | 中       | 极高       | 苹果生态高质量音频           |
| **PCM**  | **是**   | **很大** | **极高**   | **音频处理、编码中间格式**   |
| **MP3**  | **否**   | **小**   | **较好**   | **普通音乐播放**             |
| AAC      | 否       | 小       | 更好       | 流媒体、移动设备             |
| OGG      | 否       | 小       | 较好       | 开源项目、网络音频流         |
| **OPUS** | **否**   | **很小** | **非常好** | **实时音频传输、低延迟需求** |
| WMA      | 否       | 小       | 一般       | Windows 平台音乐播放         |
| MIDI     | 特殊     | 很小     | 无真实音质 | 音乐创作、合成器             |
| AIFF     | 是       | 大       | 极高       | 苹果专业音频编辑             |
| **AMR**  | **否**   | **很小** | **低**     | **手机语音通话记录**         |
| DTS      | 是       | 中       | 极高       | 家庭影院、蓝光音轨           |
| APE      | 是       | 中       | 极高       | 高质量音频存储（解压较慢）   |

#### 总结

- 如果需要 **最高音质且不考虑文件大小**，可以选择 PCM 或 WAV。
- 如果追求 **音质与存储空间的平衡**，选择无损压缩格式（如 FLAC、ALAC）。
- 如果需要 **节省存储空间并兼顾音质**，选择有损格式（如 MP3、AAC、OGG、OPUS）。
- 如果是 **语音记录**，可以选择专门的语音格式（如 AMR）。
- 如果是 **音乐创作**，可以使用 MIDI 文件。
- 如果需要 **低延迟实时音频传输**，OPUS 是最佳选择。



## 音频文件读取与处理

### soudfile库

```python
import soundfile
speech, sample_rate = soundfile.read(wav_file)
```

### torchaudio库

```python
import torchaudio
wavedata, sr = torchaudio.load(file_path, normalize=True)
torchaudio.save(out_path, wavedata, sr)

```
